## ✨ Sparkle Programming Language

![](https://img.shields.io/badge/Astro-444?logo=astro)
![](https://img.shields.io/badge/TypeScript-444?logo=typescript)
![](https://img.shields.io/badge/Rust-444?logo=rust)
![](https://img.shields.io/badge/Zig-444?logo=zig)

A lowkey, natural, and explicit programming language with minimal punctuation. Supports many modern programming features and built-in classes taking inspiration from Scala, Rust, and Python, among other programming languages.

```sparkle
let Person be class with name, and age defined with
  name as name,
  age as age,

  greet as method as
    print "hello my name is {own's name}"
  , and

  to_string as method as
    name

let alice be new Person with "alice", and 25

do alice's greet
```

This is a work in progress project in the prototyping stage that is not yet ready for production.
